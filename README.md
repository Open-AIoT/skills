# Open AIoT 官方 Skill 库（skills）

**面向设备管理场景的 Agent 技能包** —— Skill 格式规范与官方 Skill 集合。

Skill 是"完成某类设备管理任务的能力封装"：若干工具 + 提示词 + 工作流程。首批官方 Skill：设备巡检、能耗分析、远程运维助手。每个 Skill 显式声明所需权限（scope），安装时清晰可见。

> 项目状态：规划中（Phase 2 启动）。
